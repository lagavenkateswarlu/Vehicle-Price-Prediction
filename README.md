# 🚗 Vehicle Price Prediction

Machine Learning Regression Project for Predicting Vehicle Prices

## 🧠 Project Overview

This project predicts vehicle prices using Machine Learning regression techniques. The dataset contains information about different vehicle characteristics such as engine size, horsepower, fuel type, body style, and other specifications. Various regression algorithms were trained and evaluated to identify the best-performing model.

## 📁 Dataset

- Dataset: Automobile Dataset
- File: auto.csv

## ⚙️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Google Colab / Jupyter Notebook

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning
3. Missing Value Handling
4. Data Preprocessing
5. Train-Test Split
6. Linear Regression
7. Lasso Regression
8. Ridge Regression
9. Model Evaluation
10. Price Prediction

## 📊 Models Used

### Linear Regression
- Baseline regression model
- Used for vehicle price prediction

### Lasso Regression
- Applied L1 regularization
- Reduced less important feature weights

### Ridge Regression
- Applied L2 regularization
- Delivered the best overall performance

## 📈 Evaluation Metrics

- R² Score
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)

## 🏆 Results

- Ridge Regression achieved the best performance.
- Accuracy: 90%
- Prediction Error: Approximately 2440 Dollars
